# Royal Premium Coffee — Brand Website

A responsive Arabic landing-page concept for Royal Premium Coffee.

## Preview
Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.
Then GitHub will provide a public website URL.

## Included
- RTL Arabic layout
- Premium black, red and gold visual identity
- Animated CSS product pouch mockups
- Product and contact sections

## Before publishing
Replace the generic WhatsApp URL in `index.html` with the brand's real WhatsApp number in international format (Egypt: 20 followed by the number, without + or leading 0).
